# Roadmap

What is shipped, what is being built now, what comes next in order, and what is only an idea. Three rules keep it
honest: an item moves to Shipped with its date and its commit when it lands; the Next list is in the order the work
should run, not the order it was thought of; and a deliberate scope cut made in a round gets a numbered item here in
the same round, placed where it should run, so that a gap with a name also has a slot. Only ideas with no concrete shape
yet go under Later.
